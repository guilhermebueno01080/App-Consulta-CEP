# Consulta CEP

App Android simples em Kotlin que busca o endereço a partir de um CEP.

- Digite o CEP (com ou sem traço) e toque em **Buscar**.
- Mostra rua, bairro, cidade, estado e DDD.
- Avisa quando o CEP está incompleto, não existe ou quando não tem internet.
- Usa a API gratuita [ViaCEP](https://viacep.com.br).

## Como rodar

Abra o projeto no Android Studio e clique em **Run**, ou pelo terminal:

```bash
./gradlew assembleDebug
```
